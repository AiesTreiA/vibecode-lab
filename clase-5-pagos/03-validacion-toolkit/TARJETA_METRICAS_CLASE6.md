### ¿Tu propuesta de valor genera interés o hay que pivotar el mensaje?

### ¿El canal elegido es el correcto para tu perfil de cliente?
> Ejemplo: "LinkedIn funcionó mejor que Instagram porque nuestro cliente es B2B corporativo."



### Decisión: ¿Pivotar o Escalar?
- [ ] **Escalar** → El dolor está validado, el mensaje funciona, seguimos con el plan actual
- [ ] **Pivotar el mensaje** → El dolor existe pero el gancho no convierte, cambiamos la propuesta de valor
- [ ] **Pivotar el segmento** → El perfil de cliente no es el correcto, buscamos un nuevo ICP
- [ ] **Pivotar el producto** → El dolor no existe o no duele lo suficiente, reformulamos desde cero
